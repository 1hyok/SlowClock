느린 시계 (SlowClock) 개인정보처리방침

시행일: 2026년 9월 6일

느린 시계(이하 "앱")는 개인정보 보호법 등 관련 법령을 준수하며, 이용자의 개인정보를 다음과 같이 처리합니다.

1. 처리하는 개인정보 항목과 수집 방법

항목수집 시점내용
계정 정보Google 계정으로 로그인할 때이름, 이메일 주소, 프로필 사진 주소, Firebase 계정 식별자(UID)
일정 정보일정을 만들거나 수정할 때일정 제목, 시작·종료 시각, 완료 여부, 반복 설정, 메모
공유 코드계정을 처음 만들 때 자동으로 생성되고, 가족의 코드를 입력해 등록할 때본인의 공유 코드, 등록해 둔 가족의 공유 코드
기기 정보앱을 설치·실행할 때푸시 알림 전송용 기기 토큰(FCM 토큰), Firebase 설치 ID, 앱 버전, 운영체제 버전
이용 통계앱을 사용할 때앱 인스턴스 ID, 화면 이동·앱 실행 이벤트, IP 주소에서 추정한 대략적인 위치(Firebase Analytics)
진단 정보앱이 비정상 종료될 때오류 발생 지점(스택 트레이스), 기기 모델, 운영체제 버전, 앱 버전, 오류 직전의 앱 상태, Crashlytics 설치 식별자(Firebase Crashlytics)

앱은 GPS 등 기기의 정밀 위치 권한을 요청하지 않습니다. 이용 통계 서비스는 통신에 사용된 IP 주소에서 대략적인 위치를 추정합니다. 연락처, 통화 기록, 기기에 저장된 사진·파일은 수집하지 않습니다.

2. 개인정보의 처리 목적

  • Google 계정 로그인과 이용자 식별
  • 일정 저장, 정시 알람과 푸시 알림 제공
  • 공유 코드를 알려 준 사람에게 일정 열람 제공
  • 앱 오류 분석과 서비스 품질 개선

3. 보유 및 이용 기간

앱은 Firebase 계정 UID를 Analytics나 Crashlytics의 사용자 ID로 설정하지 않습니다. 이 서비스들은 별도의 앱·설치 식별자를 사용하므로 모든 원본 기록이 익명 집계 자료인 것은 아닙니다. Crashlytics는 비정상 종료 기록과 관련 식별자를 90일 동안 보관한 뒤 운영 시스템과 백업에서 삭제하는 절차를 시작합니다.

계정과 연결된 일정·공유 기록·알림 기록·계정 정보는 회원 탈퇴(계정 삭제)가 완료되면 삭제합니다. Analytics 및 설치 식별자에 연결된 기록은 계정 삭제만으로 즉시 삭제되는 항목이 아니며 각 서비스의 보유·삭제 정책이 적용됩니다. 해당 기록의 삭제 요청도 아래 문의처로 접수할 수 있습니다. 다만 관련 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다. 삭제 요청은 아래 문의처로 보내 주시면 7일 이내에 처리합니다.

4. 개인정보의 제3자 제공과 처리 위탁

앱은 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 다음 서비스에 저장·처리를 위탁합니다.

수탁자위탁 업무보관 위치
Google LLC (Firebase)인증(Firebase Authentication), 데이터 저장(Cloud Firestore), 푸시 알림(Firebase Cloud Messaging), 이용 통계(Firebase Analytics), 오류 수집(Firebase Crashlytics), 서버 함수(Cloud Functions)미국(us-central1) 등 Google Cloud 리전

공유 코드를 알려 주면 그 코드를 입력한 사람에게 이용자의 이름과 일정이 보입니다. 공유 코드를 알고 있는 로그인한 이용자는 열람을 등록할 수 있으므로, 코드가 다른 사람에게 전달되면 그 사람도 열람할 수 있습니다.

5. 개인정보의 파기

보유 기간이 끝나거나 처리 목적이 달성되면 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

6. 이용자의 권리

이용자는 언제든지 자신의 개인정보를 열람·정정·삭제하거나 처리 정지를 요구할 수 있습니다. 앱 안에서 일정을 직접 삭제할 수 있고, 계정 삭제는 앱의 내 정보 화면에서 "계정 삭제"를 누르면 일정·공유 기록·알림 기록·계정 정보가 함께 삭제됩니다. 앱을 쓸 수 없는 경우에는 문의처로 요청하면 7일 이내에 처리합니다. 절차는 계정 삭제 안내에 있습니다.

8. 안전성 확보 조치

모든 통신은 암호화(HTTPS)되며, 데이터는 Google Cloud 의 접근 통제 아래 저장됩니다. 일정은 본인 계정과 해당 공유 코드를 등록한 계정이 읽을 수 있고, 계정 정보의 이메일·기기 토큰은 본인에게만 공개됩니다. 이름은 로그인한 이용자가 사용자 식별자로 개별 조회할 수 있는 공개 프로필에 저장됩니다.
