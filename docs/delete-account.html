느린 시계 (SlowClock) 계정 삭제 안내

개발자: 정일혁 · 앱: 느린 시계 (패키지 com.ilhyok.slowclock)

느린 시계 계정과 그 계정에 연결된 데이터를 삭제하는 방법입니다. 앱 안에서 직접 삭제할 수 있고, 앱을 쓸 수 없는 경우 이메일로 요청할 수 있습니다.

1. 앱 안에서 삭제하기

  1. 느린 시계 앱을 열고 화면 위의 프로필 아이콘을 눌러 내 정보 화면으로 갑니다.
  2. 계정 삭제 버튼을 누르고 확인 창에서 삭제를 누릅니다.
  3. 삭제가 끝나면 로그아웃된 상태로 메인 화면으로 돌아갑니다.

보안을 위해 Firebase가 최근 로그인을 요구하면 로그아웃 후 다시 로그인하라는 안내가 나옵니다. 같은 Google 계정으로 다시 로그인한 뒤 계정 삭제를 다시 눌러 주세요. 네트워크 오류 등으로 실패하면 화면의 안내에 따라 재시도하거나 아래 문의처로 요청해 주세요.

2. 이메일로 요청하기

앱을 삭제했거나 로그인할 수 없다면 dnfjddk2@gmail.com 으로 로그인에 쓴 Google 계정 이메일 주소를 적어 보내 주세요. 본인 확인 후 7일 이내에 삭제하고 회신합니다.

3. 삭제되는 데이터와 보관 기간

데이터처리
계정 정보 (이름, 이메일, 프로필 사진 주소, 계정 식별자, 공유 코드)즉시 삭제
본인이 만든 일정즉시 삭제
공유 기록등록해 둔 공유 코드 감시자와, 남아 있는 그룹 구성원 기록을 함께 정리
알림 기록즉시 삭제
푸시 알림 기기 토큰계정 정보와 함께 삭제. 가족의 공유 코드에 등록해 둔 감시용 토큰도 함께 삭제됩니다
이용 통계 (Firebase Analytics)앱이 계정 UID를 사용자 ID로 설정하지 않지만 앱 인스턴스 ID와 연결된 기록은 남을 수 있습니다. 계정 삭제로 즉시 지워지지 않으며 서비스의 보유 정책이 적용됩니다. 삭제 요청은 문의처로 접수할 수 있습니다
비정상 종료 기록 (Firebase Crashlytics)앱이 계정 UID를 사용자 ID로 설정하지 않습니다. 설치 식별자와 기록은 90일 보관 후 운영 시스템과 백업에서 삭제 절차가 시작됩니다
Firebase 설치 ID 등 서비스 식별자계정과 별개로 관리되며 계정 삭제만으로 즉시 삭제되지 않습니다. 별도 삭제 요청은 문의처로 접수할 수 있습니다
